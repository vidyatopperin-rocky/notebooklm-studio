v4.6.0  (builds on v4.5.0; same layout, same UI, same resume/stop-at-limit logic)
-------------------------------------------------------------------------------
NEW
 * Per-prompt output selection. Every prompt card now has small checkboxes:
   Video, Audio, Mind map, Study guide, Briefing doc, FAQ, Blog post, Timeline (custom), Flashcards, Quiz, Note (chat answer).
   Tick what you want for that prompt; the Auto-Batch sends each ticked output, in order.
 * Presets above the batch button: "Full study pack" (audio + video + mind map + study guide + FAQ + timeline + notes),
   "Video only (v4.5 jaisa)", "Audio only". A preset is applied to every prompt; change single prompts with their checkboxes.
 * Cards from v4.5 (no output list) keep sending the video only, exactly as before.
 * Per-output progress: "P4 · Mind map (5/12)" in the batch badge, and a "✓ sent: ..." line on each card.
 * Downloadable run log: "⬇ Run log (.txt)" button next to "Clear log" (timestamps, levels, every sent output, settings header).
 * content.js: new generic Studio flow (generateStudioFlow) for Mind map / Reports / Flashcards / Quiz, and a chat flow
   (generateNoteFlow) that asks the question in the chat and presses "Save to note" on the new answer.
 * Every NotebookLM label, aria/selector and Hindi fallback for the new outputs is in the NLM_CONFIG.outputs section at the top of content.js.

RESUME / SAFETY
 * Stop-at-limit still stops before the next output; the resume point is the prompt, and outputs already sent for that
   prompt are remembered (doneOutputs on the card), so a resume does not re-send them.
 * Stop pressed between two outputs of one prompt: the prompt stays pending with its remaining outputs.
 * A "not found" (label/selector) error is retried up to 3 times like before, then stops the batch (no side effect).

CHANGED
 * "Generate later" stays off by default (v4.5 behaviour kept).
 * Dialog "Create your own" is never taken for the Generate button (added to skipButtons).

NOT DONE / CAVEATS (read README.md)
 * Only tested on a MOCK NotebookLM page in real Chromium. Real NotebookLM labels, its limit wording and its Hindi UI are unknown.
 * Timeline is NOT a built-in NotebookLM output as far as I could confirm; it runs as a custom report with a timeline instruction.
 * Infographic, slide deck, data table: not added (not in the batch).
 * Google's help pages call the product "Gemini Notebook" in places; the extension matches the same notebook URLs as v4.5.
